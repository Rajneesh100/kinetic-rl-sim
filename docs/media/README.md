# Demo media

These are captures of the running Kinetic Simulation interface on an Apple Silicon Mac, recorded on 12 October 2026.

- `scene-editor.jpg`: vehicle scene with subject tracking and engine telemetry.
- `policy-integration.jpg`: HTTP integration workspace.
- `wind-tunnel.jpg`: NACA 0012 flow experiment with smoke and streamlines.
- `vehicle-tracking.mp4`: the scripted vehicle controller with Follow subject enabled.
- `wind-tunnel.mp4`: the independent 2D incompressible flow solver advancing in the browser.
- `kinetic-demo.mp4`: both clips in sequence.
- `kinetic-demo.gif`: a smaller looping preview for the README.

The videos are assembled from sequential browser screenshots using their capture timestamps and encoded as H.264 at 20 fps. The GIF is reduced to 8 fps. Simulation time is displayed by the application and differs from wall-clock playback time. No frames were generated by an image model.

The vehicle controller is scripted, not a trained policy. The flow solver is an educational 2D model with free-slip boundaries; it does not compute calibrated aerodynamic lift or drag. See [physics models](../physics.md) for the model boundaries.
